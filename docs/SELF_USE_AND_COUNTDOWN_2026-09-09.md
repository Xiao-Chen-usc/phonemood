# PhoneMood 自身计时与高级设置倒计时

按用户最新要求：PhoneMood 自身也计入有效使用时长；倒计时由“今天”移到“设置 → 高级设置”。本文取代此前关于“在 PhoneMood 内暂停倒计时”的说明。

- 移除 AppFilter 对自身包名的默认排除。新读取的 PhoneMood 前台使用事件按普通应用参与使用时长和提醒阈值累计；已有历史事件不做批量重写。
- 前台应用查询包含 PhoneMood，使自身产生的提醒和切入自身应用的行为使用真实前台状态。
- 页面在 RESUMED 生命周期内每秒更新显示。使用实际会话的下一阈值，并在两次记录之间作有限的显示推算，不自行生成提醒或写入使用时长。
- 修复数字与横线闪烁：记录更新延迟时不再将数字替换为横线。最多推算 45 秒后冻结显示，附“等待记录更新”说明；重新收到实际记录后校准。暂停、锁屏/中断仍不增加计时。
- 保留系统界面、锁屏等现有排除规则及用户手动排除设置。

新增测试覆盖每秒推算、记录更新后的连续性、暂停和中断、到达阈值、会话重置、时钟回退和过期数据停止推算。设备测试增加自身包名的过滤、十五分钟阈值与前台查询检查。

最终 APK 构建、64 项单元测试及 Lint 通过。模拟器设备查询超时，设备测试未完成；未报告为通过。安装包为 `dist/PhoneMood-1.4.4-advanced-countdown-fix-debug.apk`。
