# Export Samples Produced by the Real Engine

*Chinese version: [README.zh-CN.md](README.zh-CN.md)*

These three JSON files were generated by `AnalysisTest` using the same Android
`PeriodDatasetBuilder`, `StatisticalEngine` and `PeriodExport` that ship in the app. The only
edit afterwards was setting `data_origin` to `SYNTHETIC_TEST_FIXTURE`. **They exist for reading
and for schema/business validation. They are not real user data.**

- `PhoneMood_1d_SYNTHETIC.json` — a single-day snapshot, including a day that may still be in
  progress.
- `PhoneMood_7d_SYNTHETIC.json` — a rolling seven calendar days.
- `PhoneMood_30d_SYNTHETIC.json` — a rolling thirty calendar days.

The per-app variation, the tendency toward continuous use, and the daily trends in these samples
are all computed from fixed synthetic inputs. This lets a future reader — including an AI reading
`statistical_analysis` — go back to the raw `analysis_matrix` and `transitions` and check the
numbers for themselves.
