The main project READMEs use three screenshots captured directly from the Android emulator on September 8, 2026. The installed prototype reported version **1.4.0**, version code **7**. The captures show the installed build; later source changes may differ.

All displayed usage and mood records are **synthetic demonstration data**, temporarily loaded into the emulator to illustrate the interface. The example app names Reading, Messages, and Video are fictional. The screenshots are unedited screen captures and do not show participant data or study findings.

The emulator's original app database, settings, and Usage Access setting were restored after capture. Exports generated from the demonstration records were removed.

Other images in this directory document earlier development and interface checks; they may show older navigation or preview modes.
